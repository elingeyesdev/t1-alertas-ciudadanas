# P01 Alertas Ciudadanas

Starter workspace for a Laravel backend and Flutter mobile application. No alert-domain behavior is implemented yet.

## Projects

| Path | Purpose | Start |
|---|---|---|
| `web/` | Laravel backend | `cd web && php artisan serve` |
| `movil/` | Flutter mobile app (`alertas_ciudadanas`) | `cd movil && flutter run` |

Run backend checks with `cd web && php artisan test`; run mobile checks with `cd movil && flutter test` and `flutter analyze`.

See each project's README for setup details. `docs/` contains project documentation; `.github/workflows/` is reserved for CI workflows.
