# Trabajo con GitHub en t1-alertas-ciudadanas

- Nunca crees ni abras pull requests en GitHub para este repositorio, incluidos los borradores. La regla aplica a cualquier herramienta, integración, navegador, CLI o API.
- Deja el trabajo en el entorno local para que el usuario lo revise. Publica una rama mediante `git push` únicamente si el usuario pide expresamente ese envío. Un permiso para publicar una rama no autoriza abrir un PR.
- Las solicitudes de implementar, terminar, verificar o entregar cambios no autorizan acciones sobre pull requests. Modifica o cierra un PR existente únicamente si el usuario pide esa acción sobre ese PR.
